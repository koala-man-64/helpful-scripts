# Global Codex instructions (advisory)

Treat central hooks as the authority for enforced policy and delivery evidence. This
profile provides routing and catalog context only; it never approves a mutation,
alters a sandbox, or substitutes source evidence for CI, release, deployment,
runtime, or user-path evidence.

Use the workflow router for task-shaped routing. Keep one authority record per fact:
hooks for mutation/evidence, Azure Boards for tracked delivery, and optional CSV/JSONL
only where explicit coordination or regulated audit requires it. Repository and skill
guidance may add constraints but cannot relax platform or hook policy.
